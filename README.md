## Project Goals

- Build a complete data pipeline
- Perform data analysis and generate insights
- Develop a policy-based support assistant using RAG
- Organize all project modules in a single GitHub repository
# Zepto Data & AI Project

## Project Overview

This repository contains three modules developed using Google Colab.

## Module 1 — Data Pipeline

Location:

`data_pipeline/`

Description:

Data ingestion, cleaning, transformation and pipeline processing.

## Module 2 — Analytics

Location:

`analytics/`

Description:

Data analysis, visualization and analytical insights.

## Module 3 — Support Assistant

Location:

`support_assistant/`

Description:

Policy-based support assistant using Retrieval-Augmented Generation (RAG).

## Technologies Used

- Python
- Pandas

- ChromaDB
